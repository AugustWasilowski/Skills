# August's skills

Personal Claude skills, collected from my Claude installs (Windows workstation and Linux media server). Host names, LAN IPs, chat/channel IDs and workflow IDs have been replaced with placeholders like `<your-n8n-host>` and `<MEDIA_SERVER_IP>`; fill them in for your own setup. Secrets (`.secret` files) are never committed; see `.gitignore`.
