# August's skills

Personal Claude skills, copied from my local install. Host names, LAN IPs, chat/channel IDs and workflow IDs have been replaced with placeholders like `<your-n8n-host>` and `<MEDIA_SERVER_IP>`; fill them in for your own setup. Secrets (`.secret` files) are never committed; see `.gitignore`.

|---|---|
| discord-update | Post an update to a Discord channel as a bot |
| fts-texture-optimizer | Run a texture audit pass on an Unreal project folder |
| holographic-prison-book-machine | Chapter-writing loop for a sci-fi novel in an Obsidian vault |
| holographic-prison-consistency-checker | Canon/consistency audit across the novel vault |
| holographic-prison-critique-circle | Prose critique for the novel |
| leo-plex-coordination | Coordinate two Claude machines via a Vikunja board |
| macu-report | Produce MACU Report video episodes |
| macu-studio-live-session | Boot the MACU Studio app for a live production session |
| modular-architecture-kit | Build procedural modular architecture kits |
| pcg-city-planner | Design and debug Unreal PCG buildings and city planners |
| tasks-summarizer | Weekly work summary via an n8n workflow over Memos |
| telegram-push | Push a Telegram message through an n8n webhook |
| ue-memory-audit | Unreal memory audit report from a MemReport |
| ue-texture-processor | Analyze and process game textures for Unreal |
| video-chinese-dub | Chinese subtitles and voice-cloned dub for a video |
